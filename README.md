# Лабораторная работа №2

**Выполнил:** студент 3 курса группы КБ-241 **Кулякин Арсентий**

## Цель работы
Получение практических навыков проектирования графических пользовательских интерфейсов (GUI) с помощью **Qt Designer**, а также реализация программной логики на базе **PyQt** с применением различных менеджеров компоновки (`QLayout`), элементов управления (`QRadioButton`, `QCalendarWidget`, `QTimeEdit`, `QListWidget`, `QDoubleSpinBox`) и механизмов информирования пользователя (`QStatusBar`).

## Перечень задач

### 1. «Текстовый флаг» (1 балл)
Реализация интерфейса для конфигурирования трехполосного флага. 
- Выбор оттенка для каждого уровня полотна осуществляется через независимые группы `QRadioButton` (от 3 до 5 вариантов выбора на каждую секцию).
- При нажатии на кнопку формирования («Нарисовать») генерируется результирующая текстовая строка с перечислением выбранной цветовой схемы (например: *«Красный, Зеленый, Белый»*).
- Для главного окна задан фиксированный размер (масштабирование заблокировано).

### 2. «Планировщик задач / Ежедневник» (3 балла)
Разработка модуля планирования на основе компонентов `QCalendarWidget`, `QTimeEdit` и `QListWidget`.
- Пользователь задает тему/наименование события, фиксирует дату и конкретное время его наступления.
- По нажатию кнопки добавления запись регистрируется и отображается в списке.
- Реализована автоматическая хронологическая сортировка событий по возрастанию даты и времени.

### 3. «Адресная книга» (3 балла)
Модуль для управления контактными данными.
- Предусмотрены поля ввода имени абонента и его контактного телефона.
- При сохранении созданная запись валидируется и передается на отображение в компонент `QListWidget`.

### 4. Интеллектуальная игра «Баше / Псевдоним» (4 балла)
Реализация пошаговой логической игры против алгоритмического соперника:
- Исходное состояние: куча из $N$ камней (размер пула конфигурируется перед стартом сессии).
- Правила: участники поочередно забирают от 1 до 3 предметов; победителем признается игрок, забравший последний камень.
- Первый ход закреплен за человеком; реализована валидация пользовательского ввода на корректность и границы допустимого диапазона.
- Логика бота реализует оптимальную выигрышную стратегию (дополнение хода пользователя до 4).
- Интерфейс обеспечивает наглядную динамическую индикацию текущего остатка камней.

### 5. Модуль экспресс-проверки оригинальности текста (4 балла)
GUI-утилита для сопоставления двух текстов на основе сеточных и линейных компоновок (`Layout`):
- Настройка чувствительности: выбор порогового значения сходства через `QDoubleSpinBox`.
- Построчный алгоритм анализа совпадений и вычисления коэффициента похожести.
- Запуск процесса по кнопке расчета.
- Результат верификации с цветовой индикацией статуса (пройдено / не пройдено) транслируется в нижнюю панель состояния (`QStatusBar`).

## Структура проекта
- `main.py` — основной исполняемый модуль и инициализация GUI
- `*.ui` — скомпилированные XML-описания графических форм из Qt Designer
